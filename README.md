# Cooperativa 5 de Julio R.L.

Sitio web oficial de la Cooperativa 5 de Julio R.L. — Barquisimeto, Lara, Venezuela.

## 🏢 Sobre la Cooperativa

Fundada en 1970, con 56 años de trayectoria sirviendo a la comunidad de Barquisimeto. Ofrecemos:

- **Ferias de Consumo** — Alimentos frescos a precios justos
- **Red de Salud** — Atención médica subsidiada
- **Fondo Funerario** — Apoyo solidario en momentos difíciles
- **Ahorro Comunitario** — Tasas preferenciales y créditos blandos

## 🛠️ Stack Tecnológico

- React 19 + TypeScript
- Vite 7
- Tailwind CSS 4
- shadcn/ui

## 🚀 Ejecutar localmente

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Abrir en navegador
http://localhost:5173
```

## 📦 Build para producción

```bash
npm run build
```

## 🌐 Despliegue

El proyecto está desplegado en [Vercel](https://vercel.com).

## 📁 Estructura del proyecto

```
src/
├── assets/images/     # Imágenes locales
├── components/        # Componentes React
│   └── ui/           # Componentes shadcn/ui
├── data/             # Datos del sitio (mockData.ts)
├── hooks/            # Hooks personalizados
├── lib/              # Utilidades
├── pages/            # Páginas (rutas)
├── App.tsx           # Componente raíz
├── main.tsx          # Entry point
└── types.ts          # Interfaces TypeScript
```
